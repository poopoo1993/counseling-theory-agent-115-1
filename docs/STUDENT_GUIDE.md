# 學生使用說明

使用本系統前請準備兩個帳號。兩者用途不同，不需要互相綁定。

## 需要準備的兩個帳號

1. 學校 `@hcu.edu.tw` 信箱：接收 OTP 驗證碼並登入 Agent。
2. 個人 `@gmail.com` 帳號：登入 Google AI Studio，申請自己的 Gemini API Key。

Google 目前的 API Key 類型與建立流程可能調整，請以 [Gemini API Key 官方頁面](https://ai.google.dev/gemini-api/docs/api-key) 顯示為準。額度、可用模型及計費狀態也以學生帳號當下頁面為準。

## 第一次使用

1. 在 Agent 首頁輸入學校 Email。
2. 按「寄送驗證碼」，到學校信箱收取六位數 OTP。
3. 輸入 OTP 完成登入。
4. 用個人 Gmail 開啟 [Google AI Studio](https://aistudio.google.com/)，依頁面指示建立或查看 Gemini API Key。
5. 回到 Agent，將自己的 Key 貼入密碼欄位並按「測試 API Key」。
6. Key 只在目前瀏覽器工作階段使用；關閉或重新登入後可能要再貼一次。

## 兩種練習模式

### 學派體驗

你擔任個案，AI 擔任該學派的示範諮商師。可使用虛構或低敏感度的內容，不需要揭露真實隱私。晤談中不會顯示技巧名稱；結束後才會解析 AI 在哪一句使用哪些技巧。系統不會對你的自我揭露或「個案表現」打分。

### 學派實作

你擔任諮商師，AI 擔任標準化模擬個案。先從該學派 5 項技巧中勾選恰好 3 項；系統會建立適合練習這些技巧的案例。結束後可看到形成性分數、具體優點、改善焦點及替代回應。

## 非語言訊息

括弧表示非語言行為，例如：

- （語氣放緩）
- （停頓數秒）
- （眼神移開）
- （身體微微緊繃）

括弧內容會完整保存在逐字稿中。請只寫可觀察的行為，不要在括弧內寫診斷或推測，例如不要寫「（其實有憂鬱症）」或「（害怕被拋棄）」。

## 續談與逐字稿

完成一個 Session 後，可在下次登入選「續談上次歷程」。實作模式會延續同一位 AI 個案；體驗模式會延續同一位 AI 諮商師。實作結束後可自行下載 TXT 逐字稿。體驗模式結束時會詢問是否作為研究素材：不願意則不保存晤談過程；願意可再勾選匿名，晤談過程另存不記名資料表。

## 隱私與安全

- 不要輸入真實個案姓名、電話、地址、學校、公司或其他可識別資訊。
- 不要把自己的 API Key 傳給同學或貼在聊天室、逐字稿、作業及截圖中。
- 系統不是心理治療或危機服務。如果你或他人有立即安全風險，請停止模擬並聯絡真人協助；在臺灣可撥 119、110 或安心專線 1925。
- AI 回饋是形成性練習參考；正式學期評量仍由教師依課程規則判斷。
