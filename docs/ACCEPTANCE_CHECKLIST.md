# 上線前驗收清單

## 登入與權限

- [ ] `@hcu.edu.tw` 可收到 OTP 並登入。
- [ ] 非允許網域無法登入。
- [ ] Secrets 白名單中的教師測試 Email 可登入並看到教師後台。
- [ ] 學生無法看到教師後台。
- [ ] API Key 留白或無效時不能開始模擬。
- [ ] Google Sheets、逐字稿及後台中查不到學生 API Key。

## 學派與雙模式

- [ ] 畫面正好顯示 11 學派。
- [ ] 每學派正好顯示 5 技巧。
- [ ] 實作模式未選恰好 3 技巧時不能開始。
- [ ] 體驗模式中 AI 只當諮商師，晤談中不說出技巧標籤。
- [ ] 實作模式中 AI 只當個案，不突然教學或評分。
- [ ] 案例背景能支持所選三技巧，而非隨機脫鉤。

## 非語言訊息與安全

- [ ] AI 偶爾自然使用括弧非語言訊息，不是每句都有。
- [ ] 學生括弧內容原封不動出現在 ChatLogs 與下載逐字稿。
- [ ] 電話、Email 或身分證格式會被介面阻擋並要求移除。
- [ ] 明確即時自傷／他傷語言會停止角色模擬並顯示真人求助方向。

## 形成性回饋

- [ ] 體驗模式不評分學生的個案表現。
- [ ] 實作模式分數為 5 個向度，各 0 至 20 分。
- [ ] 回饋先呈現 2 至 3 個有逐字稿證據的具體優點。
- [ ] 回饋能區分已使用、錯失機會、沒有適當機會及同學派延伸技巧。
- [ ] 至少提供具體改善方向與替代回應。
- [ ] AI 分數與教師人工成績分開保存。

## 續談

- [ ] 實作模式可續談同一位 AI 個案。
- [ ] 體驗模式可續談同一位 AI 諮商師。
- [ ] 續談保持同一學派、人物／互動風格、已揭露內容與未完成議題。
- [ ] 實作續談可重新選擇同學派的三項技巧。

## 後台與研究資料

- [ ] 九張 Google Sheets 工作表自動建立且第一列欄名正確。
- [ ] 教師可依 Email 查看次數、時間、模式、學派、技巧與逐字稿。
- [ ] Sessions、ChatLogs、Assessments 與 SkillEvents 均保留版本欄位或關聯 ID。
- [ ] 教師可下載完整 CSV 壓縮檔。
- [ ] IdentityMap 能在研究匯出後獨立移除，其他表仍可由 participant_id 關聯。
